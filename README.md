# Бронирование переговорных комнат

Веб-приложение для управления бронированием переговорных: список комнат, создание, изменение и отмена броней, календарь занятости, поиск свободных комнат, отчёты по использованию. Пересечение встреч в одной комнате исключено на уровне БД.

**Статус:** проектирование, код не начат. Прогресс — в [PLAN.md](PLAN.md).

## Стек

- Backend: Python 3.12, FastAPI, SQLAlchemy 2, Alembic, pytest
- Frontend: Vue 3, Vite, TypeScript
- БД: PostgreSQL 16 (Docker)

## Возможности

- Просмотр комнат (вместимость, оборудование)
- Создание, изменение, отмена бронирований
- Проверка пересечений интервалов (полуоткрытые `[start, end)`)
- Календарь: комнаты × время
- Поиск свободных комнат на интервал
- Отчёты по загрузке, экспорт в CSV
